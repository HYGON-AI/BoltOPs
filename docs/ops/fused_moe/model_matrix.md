# Fused MoE 网络 Shape 与 Triton 3.6 训练清单

## 数据口径

- Shape 来源：`/public/home/zhenxin/op_shape_perf_data` 的 `dev` 分支，revision
  `767d0342e88477b0b97dc4d8fc380bdf11e58d99`。
- 配置状态基于本提交的
  `boltops/fused_moe/triton/configs/triton_3_6`。
- 只读取 `*/bw1101/moe/*.csv` 中 `op_name=fused_moe` 的记录；同一模型、
  dtype、TP、EP、E、N、K、topk 下重复的 DPA/DP/PP/CP 组合合并为一行。
- 表中的 E、N 均为 CSV 给出的单卡本地维度；K 为 `model_dim`，M 为
  `token`，带 batch 的数据使用 `M=batch×token_per_req`。
- `bw1101` 按 gfx938 匹配。FP8/INT8 W8A8 数据未声明 block shape，按
  channel-wise 配置匹配；INT4/MXFP4 当前 3.6 目录没有对应配置。

状态定义：

- `精确训练`：存在相同 E/N/K/topk/arch/dtype 的 Gemm1 与 Gemm2 JSON。
- `模糊覆盖`：无精确 K，但命中相同 E/N/topk/arch/dtype 的 `KMin/KMod`；
  它表示可复用，不表示对该网络 K 做过专项 autotune。
- `未训练`：既没有精确配置，也没有可命中的模糊配置。
