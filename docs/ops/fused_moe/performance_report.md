# Fused MoE 性能报告：BoltOPs vs Aiter

> 测试时间：2026-09-01～2026-09-02。本轮使用当前提交中的 BoltOPs 代码，在 BMZ（BW200）和 NMZ（BW1100）上重新实测全部 16 个 case；使用 Triton 3.6、真实 fused-topk routing、topk=8，且不带 shared expert。

> 仓库只保留可复核的汇总数据；运行日志、缓存和原始 JSON 位于测试环境的 `.tune_runs`，不作为源码仓库的一部分提交。

本报告按机器整理：先列 BMZ 的整体结果与各配置逐 M 数据，再列 NMZ。BMZ 9 个、NMZ 7 个 case 均完整结束，每个 case 覆盖 17 个 M（1～32768）。

正提升表示 BoltOPs 更快，计算公式为 `(Aiter - BoltOPs) / BoltOPs * 100%`。“平均提升”是表内各 M 的有符号提升算术平均值，不是总耗时比。ASM 与 HIPC/MOE_C 分别比较；按约定，只要 provider 真正执行对应计算并返回有效时长才参与性能统计，不按 Aiter provider 的数值正确性结果筛选。

> 2026-09-01 补充核验：使用 `aiter-0.1.5+das185.dtk2604.torch2100.2608131714.gb0979d` wheel 复测后，确认 INT8 block [128,128] 不支持 HIPC/MOE_C。旧测试强制进入 MOE_C wrapper 时，block-wise Gemm1/Gemm2 的 launch 代码实际被编译关闭，所得时长不包含两次 GEMM，不能作为性能数据；本报告已删除这两组无效的 HIPC/MOE_C 数据。

## Aiter native backend 支持概览（当前 wheel）

Aiter 先按数据/量化类型以及 channel-wise/block-wise 布局决定候选 backend，再按 GPU 架构、E/N/K、topk 和 M 查找 native config。因此下表的“支持*”表示当前 wheel 存在该 backend 路径，不代表所有具体尺寸都有可用 config。

| 数据类型 | 量化/布局 | ASM（原始权重） | ASM Shuffle Weight | HIPC/MOE_C | MOE_C 权重布局 |
|---|---|---:|---:|---:|---|
| BF16 | W16A16 | 支持* | 支持*（独立 shuffle CSV） | 不支持 | — |
| INT8 | W8A8 channel-wise | 支持* | 支持*（独立 shuffle CSV） | 支持* | 强制预 Shuffle，无 non-shuffle 版本 |
| FP8 | W8A8 channel-wise | 支持* | 支持*（独立 shuffle CSV） | 支持* | 强制预 Shuffle，无 non-shuffle 版本 |
| INT8 | W8A8 block [128,128] | 支持* | 支持*（独立 shuffle CSV） | 不支持 | — |
| FP8 | W8A8 block [128,128] | 支持* | 支持*（独立 shuffle CSV） | 本轮尺寸无 native config | — |

ASM 与 ASM Shuffle 是两套独立 solution table，可能只有其中一套存在某个尺寸的 config。MOE_C 则只有一种运行口径：当该类型/尺寸可用时，权重必须先 shuffle，报告中的 `HIPC/MOE_C 预 Shuffle` 列就是这个版本。本报告按之前约定不包含 INT4。

## Aiter CI 测试方法交叉验证

以上主表使用训练工作负载（真实 routing、无 shared expert）同时测量 BoltOPs、ASM、ASM Shuffle 与 HIPC。另直接调用 Aiter 源码 `op_tests/ci_tests` 中对应函数，对本轮新训练尺寸的 17 个 M（含 32768）做交叉验证。预处理与 weight shuffle 均在计时区间外。

Aiter 当前 channel-wise CI CLI 会把 INT8 也传成 FP8 输入，触发 `input_tensor_q` 未赋值；INT8 复核保留其 CI 函数和执行路径，只把输入/输出改为与本轮训练一致的 FP16。FP8、BF16 与 INT8 block 未修改输入口径。

“与主表平均/最大绝对差”只对 CI 实际选中的同名原生 provider 比较；Aiter Triton 与 BoltOPs 不是同一 provider，因此不强行比较。

| 机器 | Config | CI 源文件 | 完成项 | CI backend | 与主表平均绝对差 | 最大绝对差 |
|---|---|---|---:|---|---:|---:|
| BMZ | BF16 / E128 / N768 / K4096 | `test_aiter_moe_with_config_w16a16.py` | 17/34 | triton | — | — |
| BMZ | INT8 block [128,128] / E256 / N128 / K7168 | `test_aiter_moe_with_config_w8a8_blockwise.py` | 17/17 | asm | 3.73% | 17.69% |
| NMZ | FP8 channel / E160 / N320 / K6144 | `test_aiter_moe_with_config_w8a8_channelwise.py` | 17/34 | asm | 3.25% | 13.59% |
| NMZ | FP8 channel / E256 / N320 / K7168 | `test_aiter_moe_with_config_w8a8_channelwise.py` | 17/34 | moe_c | 2.49% | 6.55% |
| NMZ | INT8 channel / E256 / N128 / K7168 | `test_aiter_moe_with_config_w8a8_channelwise.py` | 34/34 | asm, asm shuffle | 5.01% | 17.49% |
