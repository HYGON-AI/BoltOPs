# 2026-10-14：最新 Triton 3.6.x 的 WDRA48 小用例复测

仅部分复现历史记录：512³ 普通 WDRA48 正确性通过，性能超过旧普通版；256×256×4096 MLS 正确性通过，性能比历史约低 3.5%；512³ MLS 历史最佳 tile 在编译期失败。

## 参数与可比性

| 用例 | tile M×N×K | 分区 waves | VGPR load/main/tail | stages | mlf | cluster | MLS / matrix-store |
| --- | --- | --- | --- | ---: | ---: | ---: | --- |
| 512³ 普通版 | 128×128×128 | (4,4,4) | 160/160/160 | 2 | -1 | 0 | 否 / 否 |
| 512³ MLS（编译失败） | 128×128×128 | (4,4,4) | 160/160/160 | 2 | 3 | 1 | 是 / 是 |
| 256×256×4096 MLS | 256×256×64 | (4,4,4) | 16/244/244 | 2 | 3 | 0 | 是 / 是 |

共同参数：empty_arrive_after_mmac=False、optimize_epilogue=True、buffer cache swizzle=True、buffer ops=True；matrix-store interleave=2；未强制 matrix-store 指令种类。

boltOps 仍传递旧 WASP/WDRA 参数，直接运行出现 `KeyError: Keyword argument wasp_enabled was specified but unrecognised`。本次仅在工作区测试驱动中转换参数，没有修改 GEMM 内核或 Triton：

- load=4、mma=8 转成 wasp_partition_warps=(4,4,4)。
- wdra_enabled 转成 wasp_wdra，三个 VGPR quota 转成 wasp_partition_regs。
- 删除已取消的 wasp_enabled 等后端参数，保留内核 constexpr WARP_SPECIALIZE。
- 最新 Triton 固定启用 consumer ping-pong。512³ 驱动请求 pp=False，实际仍启用；CSV 中 pp=0 是旧输入参数，不是实际流水线状态。

因此普通版 +13.53% 不能证明完全相同流水线下的编译器提升。256×256×4096 的历史配置本身为 pp=True，更接近本次；约 3.5% 的差异重复测量稳定，但尚未归因到具体 Triton/LLVM 提交。

## 512³ MLS 编译失败

历史 tile 128×128×128 在 TritonHCUMlsEncodingInsertion 中失败，尚未执行内核：

```text
MlsEncodingInsertion.cpp:154
Assertion `kTile != 0 && "pre select mls tile failed, no candidate survived"` failed.
RuntimeError: PassManager::run failed
```

这是 MLS 编码选择阶段的失败，不是正确性失败或低性能结果。本次未改 tile 来替代历史最佳配置。

本节描述 2026-10-14 的测试方式；2026-10-15 已正式迁移调用端，后续直接使用 `python -m boltops.tools.tune_gemm_wasp`，不再使用临时适配驱动。详情见 [迁移记录](OPTIMIZATION.md)。

测试驱动 run_gemm_case.py 与 perf-env.sh 位于工作区根目录。进入当前容器后 source perf-env.sh，在新的运行目录调用驱动；输出读取限制在该目录，使用 --no-wipe 避免触及其他工作区产物。

```bash
python "$GEMM_OPT_ROOT/run_gemm_case.py" \
  --mnk 256x256x4096 --mode wdra48 --skip-nowasp \
  --blocks 256x256x64 --empty-arrive false --cluster 0 \
  --consumer-pingpong true --num-stages 2 --mmac-layout-force 3 \
  --wdra-load-regs 16 --wdra-mma-main-regs 244 --wdra-mma-tail-regs 244 \
  --ab-layout TT --mls --matrix-store --matrix-store-interleave 2 \
  --check --no-wipe --out result.csv
```
